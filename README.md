# GeoLearner Recommender

Python-пакет с NLP- и рекомендательной логикой проекта GeoLearner. Содержит инструменты для анализа пользовательских запросов, семантического поиска и формирования рекомендаций на основе текстовых характеристик произведений.

Репозиторий включает только алгоритмы и не содержит базы данных, каталогов произведений, готовых эмбеддингов или инструментов сбора данных.

## Возможности

- **Query Analysis** — анализ и структурирование пользовательских запросов с помощью Qwen.
- **Query Moderation** — проверка пользовательских запросов на осмысленность.
- **Semantic Search** — поиск произведений по смысловому сходству с использованием E5.
- **Content Filtering** — фильтрация по типу контента, стране, году и автору.
- **Relevance Evaluation** — дополнительная проверка соответствия найденных произведений запросу.
- **Deduplication** — обнаружение одинаковых произведений, альтернативных названий и переводов.
- **Title Translation** — перевод названий книг на русский язык.
- **Result Ranking** — ранжирование и формирование итоговой выдачи.

### Назначение модулей

**nlp/** — обработка естественного языка и взаимодействие с языковой моделью Qwen.

**filters/** — фильтрация произведений по метаданным.

**recommendation/** — семантический поиск, работа с эмбеддингами E5, ранжирование и формирование рекомендаций.

## Архитектура

Модели, метаданные и готовые эмбеддинги передаются рекомендательной системе извне. Пакет отвечает за обработку запросов, поиск, фильтрацию и ранжирование результатов.
