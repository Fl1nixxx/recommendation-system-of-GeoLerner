# Learner Recommender

Python-пакет с NLP- и рекомендательной логикой проекта Learner. Репозиторий содержит только алгоритмы: он **не содержит** каталоги, SQLite-базы, готовые эмбеддинги или скрипты их построения.

## Что входит

- анализ пользовательского запроса через Qwen;
- проверка осмысленности запроса;
- семантическое представление запроса и поиск через E5;
- фильтрация по типу контента, стране, году и автору;
- дополнительная проверка релевантности через Qwen;
- дедупликация названий и переводов;
- перевод названий книг на русский;
- формирование DataFrame с результатами.
